## 2. この版で入れた改善

- **オフライン**：フォントを同梱し（約480KB）、外部への要求をなくしました。
  - 文字の追加があったら `python3 tools/build-fonts.py <ttfのフォルダ>` で作り直します。
  - `--check` で、使っている文字がフォントに入っているかを確かめられます。
- **保存**：iOS では Capacitor Preferences と localStorage の両方に書き、起動時に新しい方を採用します。WebView の localStorage が消されても、進行は残ります。
- **振動**：選択・狙い・滴下・捕食・侵入・判定に、短い振動を割り当てました。設定でオフにできます。
- **画面**：ノッチ・ホームバー・横向きの余白、ゴムバンド、拡大の無効化、長い画面でも固定された「閉じる」ボタン、最小11pxの文字、44pt以上のタップ領域。
- **音**：
  - 音楽をオフにしても残っていた残響の漏れを直しました。
  - 全体の音量を引き上げ、リミッターを付けました。
  - 効果音を音楽より十分に大きくしました（`tools/petri-audio.mjs` で計測）。
- **初見**：
  - 初回は「増殖」の菌を先頭に置いて「おすすめ」を付ける。
  - 序盤3日の目標を 30% → 34% → 38%（その後は従来どおり）に変更し、1日目は侵入株の入り方も穏やかにしました。
  - 失敗時に原因のひとこと。
- **描画品質**：設定に「皿の描画：自動／軽め」。自動のときも、極端に遅い端末ではすばやく解像度を下げます。

### 初見の人が1日目をどれだけ通過できるか（自動プレイでの見積もり）

初見の人の遊び方を3通りに模擬して、1日目を通過する割合を測りました（各4,000回）。目標を下げ、1日目の侵入株を少なくする前後を比べます。

| 遊び方 | 以前 | 現在 |
|---|---|---|
| 菌も場所もランダムに落とす | 43% | 61% |
| 場所は散らすが、菌はランダムに選ぶ | 57% | 75% |
| 「増殖」の菌を選んで、場所を散らす | 83% | 92% |

- 以前は、1日目で約半数が負けていました。原因は、勝ちやすさがほぼ「増殖」の特徴で決まることです。「増殖」のある菌は1日目の平均占有率が55〜79%、「共生」「胞子」「殻」だけの菌は16〜19%です。
- 菌の選び方がランダムの模擬プレイヤーが3日目に届く割合は、20% → 34%になりました。
- 熟練者向けの難しさは変えていません（計画的な自動プレイの勝率は、どちらも約20%）。

**人で確かめること**：実際の人が「増殖」を選ぶか、「おすすめ」を見落とさないか、失敗したときのひとことで次の手が変わるか。

## 3. 実機での確認手順（Mac と iPhone が必要）

### 3-1. 描画の滑らかさ
1. シャーレの URL（またはアプリ内）を `?bench` 付きで開きます。
2. 「計測を始める」を押し、約30秒待ちます。
3. 結果の画面を撮影するか、「結果をコピー」で数値を取ります。保存データには影響しません。

| 結果（95%のフレーム時間） | 判定 | 対応 |
|---|---|---|
| 20ms 以下 | 良好 | そのまま |
| 34ms 以下 | 許容 | 設定の「軽め」で改善するか確認 |
| 34ms 超 | 要対策 | `?bench&low`（軽め）で再計測。それでも超えるなら、描画の簡略化が必要 |

**確認する機種**：発売年の古い順に、できれば iPhone SE（第2世代）、iPhone 11〜12、最新機種。
**見るもの**：3分連続で遊んだあとの本体の温度と、電池の減り方。

### 3-2. 音
- 実機のスピーカーとイヤホンの両方で、音楽・効果音の大きさを確かめます。
- マナーモードの扱いを決めます。WebView の音は、既定ではマナーモードで消えます。音を出したい場合は、アプリ側で音声セッションの設定が必要です。
- 客観的な測定は `node tools/petri-audio.mjs` で確認済みです（音割れなし、音楽オフは無音、効果音は音楽より大きい）。

### 3-3. 振動
- 選ぶ・狙いを動かす・滴下・侵入・成功・失敗の6場面で、強さが適切か確かめます。
- 狙いを動かすときの細かい振動が、うるさく感じないかを確認します。

### 3-4. オフラインと中断
- 機内モードで起動して、フォントが崩れず最後まで遊べること。
- 培養の途中でアプリを終了して再起動し、「つづきから」で同じ状態に戻ること（滴下をやり直せないこと）。
- 電話の着信やホームへ戻ったときに、一時停止になること。

### 3-5. 画面
- ノッチやダイナミックアイランドに上部のバーが隠れないこと。
- ホームバーにカードが重ならないこと。
- 機種を変えて、遊び方の画面が最後まで読めて、閉じられること。

## 4. 既存の Capacitor プロジェクトへの組み込み

シャーレは静的ファイルだけなので、`petri/` を Web アセットとして取り込みます。

```
# 例：アプリの webDir に petri/ の中身を置く
cp -R petri/* <app>/www/
npx cap sync ios
```

**必要なプラグイン**（すべて公式。無ければゲームはブラウザ版と同じ動きになります）
- `@capacitor/preferences`：保存
- `@capacitor/haptics`：振動
- `@capacitor/app`：バックグラウンドの検知（任意。`visibilitychange` でも代用できます）

ゲームは `window.Capacitor.Plugins` 経由で呼ぶので、バンドラは不要です。

**推奨の設定**
- `capacitor.config.json`：`ios.backgroundColor` を `#10161a`（起動時の白い一瞬を防ぐ）。
- Info.plist：画面の向きは縦のみ。
- 起動画面の背景も `#10161a` に合わせます。
- ステータスバーは明るい文字（Light content）にします。

**アプリが提供するもの**：ゲーム側は `?bench`（計測）、`?seed=...`（同じ皿の再現）を受け付けます。
