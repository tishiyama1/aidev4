# シャーレ 正式版 — 分析・方向性・実装計画

## 1. 現状分析

### このゲームの本質的な面白さ
- **間接操作**：プレイヤーは菌を直接動かせない。決められるのは「どこに・何を・いつ落とすか」という初期条件だけ。
- **見守る緊張**：落とした一滴が勝手に広がり、侵入株とせめぎ合う8世代を、手を出せずに見届ける。
- **読み解く快感**：皿の環境（光・栄養・抗生物質・気泡）、侵入口、菌の特徴を読み、置く場所を決める。その読みが当たった瞬間が気持ちいい。
- **ランの成長**：株を増やし、特徴を接ぎ木して、自分だけの「培養ライブラリ」を育てる。

### 提供すべき感情
静かな集中、生き物を見守る愛着、じわじわ迫る緊張、そして読みが当たったときの小さな達成感。派手な興奮ではなく、顕微鏡を覗き込むような没入感。

### プロトタイプ感の原因
| 領域 | 問題 |
|---|---|
| 皿の描画 | 菌が六角格子上のコイン状の円で、生き物に見えない。環境は格子の円を色付けしただけでノイズになり、光の当たり方もマスの集合に見える。ガラスや寒天の質感がない |
| 特徴の表現 | 小さな模様（棘・点・点線）は実寸では判別できない。色は特徴と無関係に割り振られ、株に名前もない |
| 画面構成 | 情報が上部の小さな点とテキストに散らばっている。成否を決める「割合と目標」が、リングの目盛りと小さな文字でしか読めない |
| 演出 | 滴下の瞬間に視覚的な手応えがない。日の終わりの判定が無音同然の切り替えで、成功も失敗も印象に残らない。日の開始も同じ皿が切り替わるだけ |
| サウンド | 単発の電子音のみ。環境音・音楽がなく、世界観を支えていない |
| 導線 | ルールは文章の壁で、1日目に何をすればいいかを体で覚える導線がない |
| 正式版機能 | ポーズ・設定（音量／演出軽減）・続きから・記録・ラン後に残るものがない |

### 残すもの
- シミュレーションの規則とバランス（`sim.js`）。ヘッドレス検証で「上手い人ほど勝つ」ことを確認済み。
- 1日3滴×8世代×7日の構造、報酬（新しい株・接ぎ木）、最終日の適応する侵入株。
- 押して狙い、離して落とすタッチ操作。
- ルール説明の内容（表現は作り直す）。

### 再設計するもの
皿の描画、配色と株の命名、画面構成、全画面遷移、演出、サウンド、チュートリアル、保存。

### 不足している正式版機能
- 続きから（ラン途中の保存と復元）
- 設定（音量・BGM・効果音・演出軽減・培養速度）
- ポーズメニュー
- 戦績
- ラン後に残るもの（標本棚）
- 体験型チュートリアル
- WebGL 非対応環境へのフォールバック

### 技術的な制約とリスク
- 静的ホスティング（GitHub Pages）・ビルドなし。アセットはコードで生成するか、軽量ファイルにする必要がある。
- iPhone Safari では Canvas の `ctx.filter` が使えない環境がある。有機的な描画に SVG フィルタは頼れないので、WebGL シェーダで描き、使えない場合は 2D で描画する。
- 描画負荷：皿を毎フレーム描き直すため、解像度に上限を設ける必要がある。
- localStorage は容量に上限があり、使えない環境もある。

## 2. デザイン方向性（3案）

### 案A「実験ノート」— ミニマル・精密
- **ビジュアル**：白い紙と細い罫線、等幅の数字。皿は真上から見た計測器のように描き、菌は単色の柔らかい塊にする。
- **体験**：データを読み、最適化する知的な遊び。
- **素材・フォント**：紙、鉛筆線、ゴシック体と等幅数字。
- **演出・音**：最小限の動き。クリック音と低い空調音。
- **長所**：最も読みやすく、低コスト。
- **短所**：冷たく、記憶に残らない。生き物を見守る愛着が育たない。
- **コスト**：低。
- **独自性への効果**：小。

### 案B「生命の水彩」— アート重視
- **ビジュアル**：寒天を和紙に見立て、菌は顔料がにじむ水彩の群体として描く。株は伝統色の名（茜・群青・山吹…）を持ち、ランの最後の皿は一枚の絵として残る。
- **体験**：育てて眺める、美しく静かな没入。
- **素材・フォント**：和紙、にじみ、明朝体。
- **演出・音**：にじむ成長、水滴の音、静かな環境音楽。
- **長所**：唯一無二の見た目。愛着と継続プレイの動機（標本）が生まれる。
- **短所**：にじみで境界と情報が曖昧になりやすい。シェーダ実装のコストが高い。
- **コスト**：高。
- **独自性への効果**：大。

### 案C「封じ込め作戦」— 没入・物語
- **ビジュアル**：暗いバイオラボの操作端末、ネオン、警報ランプ。各日に作戦指令が出る。
- **体験**：アウトブレイクを封じ込める緊張と使命感。
- **素材・フォント**：金属パネル、スキャンライン、等幅フォント。
- **演出・音**：警報、パルス音、ドラム。
- **長所**：目的がわかりやすく、緊張感が高い。
- **短所**：既視感のある SF 表現。見守るゲームのテンポに対して音と光が過剰で、疲れる。
- **コスト**：中。
- **独自性への効果**：中。

### 推奨：B＋A の統合「生きた水彩を、精密な器で見る」
- **皿の中（生命）**：案Bの水彩表現で描く。予測できない生命の振る舞いを、美しさとして受け取れるようにする。
- **皿の外（判断）**：案Aの精密さで作る。数字・目標・特徴を、迷わず読めるはっきりした UI にする。
- この「整然とした判断 → 制御できない生命」という対比は、ゲームの構造（初期条件を決める → 結果を見守る）そのものなので、見た目がルールを語る。
- 案Cの「緊張」は警報としてではなく、侵入株の墨色が皿に染み込む表現と、低い持続音として取り入れる。

**具体的な仕様**
- **配色**：
  - 背景：夜の机に置いたライトテーブル。暗い藍墨色の地に、皿の下だけ暖かい光が当たる。
  - 寒天：琥珀色で、粒子のノイズを乗せる。
  - 株：伝統色（茜・若竹・山吹・群青・珊瑚・浅葱、予備に萌黄・鶯）。
  - 侵入株：墨紫に、縁だけ妖しい紫が光る。
- **フォント**：表題と株名は Shippori Mincho、UI は Zen Kaku Gothic New、計測値は DM Mono。
- **菌の描画**：WebGL のフラグメントシェーダで、各マスの存在量からメタボール場を作る。株ごとの場の最大値で塗り、縁は顔料が溜まって濃くなる。中は細胞のような粒状ノイズにする。特徴は質感に出す（下表）。

| 特徴 | 質感 |
|---|---|
| 捕食 | 縁がギザギザ |
| 殻 | 縁が太く暗い |
| 毒 | 暗い斑点 |
| 光合成 | 緑の粒 |
| 休眠 | 淡い嚢胞の輪 |
| 胞子 | 外側に散る点 |
| 増殖 | にじみが広い |
| 共生 | 味方の株と接する境界が光る |

- **皿の環境**：
  - 光：格子ではなく滑らかな光の楕円で表す。
  - 栄養：茶色の細かな粒の群れ。
  - 抗生物質：青白い結晶の筋。
  - 気泡：屈折するガラス玉。
  - 毒：紫のもや。
- **UI**：上部は日数（7枚の小皿アイコン）とメニュー。皿の下に「占有バー」を置き、自分・目標線・侵入株を1本で見せる。さらにその下に手札（標本ラベル風のカード：色見本・名前・特徴アイコン）。PC では右に観察ノート（皿にいる株の割合と特徴、今日の環境）を出す。
- **タイトル**：背景で本物のシミュレーションが自動で培養されるデモ皿を回す。

**演出**（すべてルールに結び付ける）

| 場面 | 演出 |
|---|---|
| 日の開始 | 新しい皿が滑り込み、光・栄養・抗生物質・気泡が順に「調製」される。環境を読むことを促す |
| 狙い | 滴下範囲の7マスの輪郭と、落ちる菌の半透明プレビュー |
| 滴下 | 水滴が落ちて波紋が広がり、群体が中心から咲く。手応え |
| 培養 | 存在量を連続的に補間して、成長・捕食・死を滑らかに見せる。世代メーターが進む。押すと早送り |
| 侵入 | 縁から墨がにじみ出る波紋と低音。脅威の発生源をはっきり示す |
| 判定 | 占有バーが最終値まで伸び、目標線と交差する瞬間に結果を出す。成功は皿が暖かく光って和音、失敗は皿が褪色して侵入株の色が広がり、下降音 |
| 報酬 | 標本瓶のカード。選んだ瓶が手札へ収まる |
| ラン終了 | 最後の皿が「標本」として額装され、標本棚に保存される |

演出を控える場面もある。狙いと判断の時間は、背景の動きを抑えて静かにする。

**サウンド**：Web Audio で生成し、ファイルは使わない。
- 環境音楽：ゆっくり揺れるパッドと、まばらなガラスの鈴。
- 緊張層：侵入株の割合が高いほど低い持続音を強める。
- 効果音：選択・狙い・滴下・成長・捕食・侵入・成功・失敗・報酬・勝利。
- 設定：主音量、BGM・効果音それぞれのオン/オフ。

## 4. 実装結果と残課題

**実装済み**：上の計画1〜8をすべて実装しました。検証は `tools/petri-e2e.mjs` で自動化し、全シナリオが合格しています。
- 自動化した確認：
  - タイトルからチュートリアルを経て、ランの終了と標本棚まで
  - スマホでのタップ、ノート、ポーズ、設定
  - リロード後の再開（日の途中と、報酬の選択中）
  - キーボード操作と、勝利画面
  - WebGL を使わない 2D 表示
- バランス：シミュレーション規則は変更していません。`tools/petri-sim.mjs` の結果は以前と同じ水準で、計画的なプレイが平均4日以上、ランダムなプレイが1日未満です。

**追加：判定の決着演出**（プレイ評価を受けて）
- 世界観として、目標に届かなかった皿は侵入株「墨」に呑まれ、届いた皿ではあなたの菌が墨を食い尽くす。
- 判定の瞬間、その結末を皿の上で演じてから判を押す（`finale.js`）。
- 結末はシミュレーションの判定どおりで、演出は見せるだけ。保存も得点も変えない。
- 標本棚の写真は、決着の前（シミュレーションが残した状態）の皿を記録する。

**残課題・既知の制約**
- **実機の描画性能**：未計測です。ヘッドレス環境は CPU 描画なので代わりになりません。対策として、描画が遅い端末では解像度を自動で下げます。低性能端末で読みにくくならないかは、実機で確認が必要です。
- **音**：ヘッドレスでは聴けないため、エラーが出ないことしか確認していません。音量バランスは実機での調整が望ましいです。
- **やり直しの防止**：保存は滴下した瞬間に行います（結果はその時点で確定しています）。培養の途中でリロードしても、悪い滴下を取り消すことはできません。最後の滴下の後に閉じた場合は、再開すると判定から始まります。
- **アクセシビリティ**：色だけに頼らないよう、株には名前とアイコンを付けています。一方で、皿の中の状態はスクリーンリーダーで読めません（観察ノートで割合は読めます）。
